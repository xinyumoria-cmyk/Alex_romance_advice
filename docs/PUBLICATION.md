# Publication copy

This package is prepared for uploading to a repository; it does not itself publish anything.

- No API keys, login caches, environment files, participant data, unrelated desktop files or old Git history are included.
- Absolute user-home paths in selected runtime records are replaced with placeholders. Document creator metadata in the publication copy is set to `Research project`. Advice bodies are unchanged.
- Public-source advice consists of short AI-normalized paraphrases with attribution. Source content remains subject to its original terms. This package does not claim ownership of third-party source text or apply a blanket open-data license to it.
- No repository-wide license has been selected by the researcher. Repository visibility is not itself a license. Choose an appropriate code/data license before inviting unrestricted reuse.
- The teacher scenario document is included because it defines the study materials. Analysis-plan drafts, earlier v1/v2 generated batches, the external published paper PDF, and full captured webpages are outside this v3 release.
- API use was stopped at the user's request. The original runner remains stopped. Packaged live-run tooling requires explicit opt-in, new credentials or account login, and a new output directory. No live generation was performed for packaging.

All API response and CLI event files included here are historical records. They are not a newly generated batch. Future `runs/` output is ignored by Git and ZIP packaging; curate, scan and document any future result release explicitly.
