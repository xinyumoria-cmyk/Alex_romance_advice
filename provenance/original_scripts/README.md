# Historical implementation snapshots

These scripts preserve the implementation history of corpus construction, v2 eligibility, v3 selection, generation and document assembly. They may refer to the original workspace layout, internal source evidence, or earlier drafts that are not distributed here. Do not run them as the portable project workflow.

From the repository root, run `python scripts/reproduce.py` for the supported offline workflow. Use `scripts/generate.py` for optional new generations. The original API key is not included or authorized for reuse.
